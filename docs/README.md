## Adding a language

1. Create `docs/<locale>/` (e.g. `fr`, `pl`).
2. Add at least `README.md` + `VISION.md`.
3. Link it from the root README language switcher.
4. Prefer translating user-facing docs first; keep architecture ADRs in English if needed.
